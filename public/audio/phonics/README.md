# Phonics audio

Drop human-recorded MP3 files here. For each letter (lowercase), three files:

| File | Content |
|---|---|
| `a-name.mp3` | the letter name, "ay" |
| `a.mp3` | the pure phonics sound, "/æ/" |
| `a-word.mp3` | the example word, e.g. "apple" (cut from the supplied video) |

Missing files fall back to the browser voice, so the page works while you add them.
Only add recordings you are licensed to redistribute.
